# c4_relay — установка в Home Assistant

Интеграция связывает станции AlexxIT YandexStation с драйвером Yandex Relay на контроллере Control4. Нужны: HA 2024.11+ (проверено на 2026.2), установленный AlexxIT YandexStation со станциями в локальном режиме, драйвер Yandex Relay ≥ 0.1.6 в статусе `ONLINE`.

## 1. Адрес HA для контроллера

Настройки → Система → Сеть → **URL-адрес для домашней сети** = `http://<IP HA>:8123`. По IP, не по `homeassistant.local`: контроллер не резолвит mDNS. По этому адресу контроллер шлёт события (webhook) и, если прямая ссылка CDN не откроется, берёт поток через прокси AlexxIT.

## 2. Установка через HACS

HACS → ⋮ (справа вверху) → **Пользовательские репозитории** → адрес `https://github.com/xmaxzzz/yandex-relay`, тип **Интеграция** → Добавить. Затем найти **Control4 Yandex Relay** в HACS → Скачать → перезапустить HA. Обновления приходят туда же, в HACS.

Без HACS: скопировать папку `custom_components/c4_relay` из репозитория в `config/custom_components/c4_relay` на HA и перезапустить HA.

## 3. Добавить интеграцию

Настройки → Устройства и службы → Добавить → **Control4 Yandex Relay**:
- **IP контроллера**, **Порт моста** (`Bridge Port` из свойств драйвера), **Код сопряжения** (`Pairing Code`);
- **Адрес Home Assistant для контроллера** — подставляется из п. 1, проверить, что там IP.

Следующий шаг — **Станции и комнаты**: у каждой станции выпадающий список комнат Control4. Комната подбирается сама по зоне станции в HA или по совпадению имени; «— не транслировать —» — станция играет сама.

После сохранения:
- в свойстве драйвера `Paired With` — адрес HA;
- появится устройство «Control4 Yandex Relay» с плеером `Control4 <комната>` и переключателем `Трансляция в Control4 <комната>` на каждую привязанную станцию;
- примерно через 10 с у станции источник (`source`) станет `Control4 <комната>`. Если станция ещё не видит этот источник, интеграция один раз перезагрузит AlexxIT — это нормально.

## 4. Проверка (DESIGN §9, приёмка этапа 1)

1. «Алиса, включи музыку» → играет Control4 в комнате ≤ 5 с, на панели название, артист, обложка.
2. «Алиса, какая погода» → в Control4 ничего не меняется.
3. «Алиса, дальше / пауза / продолжи» → Control4 следует.
4. Next / Pause / Play на панели Control4 → станция следует.
5. Рестарт HA → через ~10 с источник станции снова `Control4 <комната>`, всё работает.
6. Перезагрузка контроллера → `Bridge Status` ONLINE, `Paired With` сохранился.
7. В комнате выбрали другой источник → станция на паузе.

Логи: в `configuration.yaml`
```yaml
logger:
  logs:
    custom_components.c4_relay: debug
    custom_components.yandex_station: debug
```
В логе c4_relay видно каждое событие драйвера (`driver event …`) и смену источника станции.

## 5. Если драйвер добавили заново

Новый драйвер — новый Pairing Code (и, возможно, порт). HA покажет «Требуется повторная настройка» у интеграции: ввести новый код и порт. Привязки станций сохранятся.

## 6. Отключить трансляцию для станции

Переключатель `Трансляция в Control4 <комната>` → выкл: источник станции становится «Станция», она играет сама, кнопки панели Control4 на неё больше не действуют. Привязку поменять: Устройства и службы → Control4 Yandex Relay → Настроить.

## 7. Громкость и калибровка комнаты

Громкость настраивается в **драйвере** (Composer → Yandex Relay → Properties), для каждой комнаты отдельно:

1. `Volume: Room` — выбрать комнату (привязанные в HA — в начале списка). Поля ниже покажут её настройки, `Volume: Current` — текущую громкость Control4, `Volume: Summary` — сводку по всем комнатам.
2. `Volume: Step %` — на сколько меняет «Алиса, громче / тише» (по умолчанию 5).
3. `Volume: Max %` / `Volume: Min %` — потолок и минимум. Удобнее так: выставить комфортную максимальную громкость с панели и нажать действие **Volume: Set Max from Current** (Actions), то же для минимума.
4. `Volume: Duck` — что делать с музыкой, пока Алиса слушает/отвечает: `Lower` — приглушить до `Volume: Duck Level %` от текущей (30), `Mute` — выключить звук, `Off` — не трогать.

«Громкость 5» ставит комнату на середину между Min и Max. Громкость, выставленную кнопкой, «громче/тише» не сбрасывают — прибавляют к ней. «Громкость 1» и «громкость 0» во время трансляции работают как «громче» и «тише» (особенность заглушённой станции). Настройки хранятся и в HA: если драйвер добавить заново, после повторной настройки интеграции они вернутся сами. Проверка: Debug Mode = On — в Lua Output видно `room … volume -> N`; в HA (`custom_components.c4_relay: debug`) — `volume command ('step', 1)`.
